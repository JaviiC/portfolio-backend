Factory

          

            
Cliente
→
            
Factory
⇢
            
Producto A
Producto B

          

          
El cliente pide un tipo de producto por nombre; nunca importa las clases concretas.

          
public class NotificationFactory {
  public static Notification create(String type) {
    return switch (type.toUpperCase()) {
      case "EMAIL" -> new EmailNotification();
      case "SMS" -> new SmsNotification();
    };
  }
}

Observer

          

            
Sujeto
⇢
            
Observer A
Observer B

          

          
El sujeto avisa a todos sus observadores de un cambio, sin conocer su lógica interna.

          
public List<String> updatePrice(double newPrice) {
  this.price = newPrice;
  for (PriceObserver o : observers) {
    o.onPriceChanged(newPrice);
    triggered.add(o.name());
  }
  return triggered;
}

Delegate

          

            
Api (contrato)
⇢
            
Delegate (lógica real)

          

          
El contrato OpenAPI queda desacoplado de la lógica de negocio real. Este es literalmente el que usa el laboratorio bancario de arriba.

          
public class BankingController implements BankingApi {
  private final BankingApiDelegate delegate;
  public ResponseEntity<AccountResponse> openAccount(...) {
    return delegate.openAccount(request);
  }
}
